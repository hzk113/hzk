Place normal item icon PNG files here.

Filename rule:
- no1.png
- no2.png
- ...
- no30.png

Optional special item icon PNG files for zukan:
- special-A.png
- special-B.png
- special-C.png
- special-D.png
- special-E.png
- special-F.png
- special-G.png

Usage:
- Inventory overlay item slots use this image for normal items.
- Clear screen reward cards also use this image for normal items.
- Item zukan can show special item images if special-*.png files are provided.

If a file is missing, the icon falls back to the box emoji (📦).
Special items keep the sparkle emoji (✨).
